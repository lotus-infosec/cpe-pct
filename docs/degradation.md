# Degradation list

Where the two targets genuinely differ, the difference is stated here rather than hidden.

| Capability                     | Self-hosted (Docker)                                      | Cloudflare (Workers Paid)                                       | Effect                                                                                                                                                            |
| ------------------------------ | --------------------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Evidence upload size           | 20 MB cap                                                 | 20 MB cap                                                       | Same. Uploads are buffered in memory for hashing because a streaming SHA-256 is not portable across both runtimes; the cap keeps that safe within Workers memory. |
| Image evidence (PNG/JPEG/WebP) | stored, no text extraction                                | stored, no text extraction                                      | You type the activity details. No OCR on either target.                                                                                                           |
| Scanned (image-only) PDFs      | stored, marked `no_text`                                  | same                                                            | Same as images.                                                                                                                                                   |
| Inline PDF extraction budget   | 20 pages / 5 s, then a background job                     | same                                                            | Large PDFs finish within about 15 s (interval tick) on Docker and within a minute (cron) on Workers.                                                              |
| Job tick latency               | ~15 s                                                     | up to 60 s                                                      | Exports and deferred extraction appear later on Workers.                                                                                                          |
| Export build                   | one pass                                                  | one pass                                                        | A failed build restarts from scratch; bundles are small. Not resumable across ticks.                                                                              |
| Backup size                    | unbounded                                                 | one Worker request                                              | Very large evidence stores may exceed what a single Worker request can assemble; split by exporting cycles individually if that ever happens.                     |
| Optional auth extra            | trusted reverse-proxy header (`AUTH_MODE=trusted-header`) | Cloudflare Access JWT gate (`CF_ACCESS_TEAM` + `CF_ACCESS_AUD`) | Both sit beside LocalAuth; the header variant grants, the Access variant gates.                                                                                   |
| Email notifications            | none                                                      | none                                                            | Webhook and Discord only.                                                                                                                                         |
| Free Cloudflare plan           | n/a                                                       | not supported                                                   | `limits.cpu_ms` is rejected on Free. The free option is Docker.                                                                                                   |
